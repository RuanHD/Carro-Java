# Questão 3 - Padrão Composite (Montadora de Carros)

Este repositório contém a solução da Questão 3. O objetivo foi mapear a hierarquia de peças de um carro utilizando o **Padrão Composite**, permitindo calcular o peso total enquanto o somatório parcial é impresso dinamicamente, tratando nós-folha e nós-compostos de forma unificada.

## Documentação do Uso de IA
A IA (Gemini) foi utilizada para guiar a estruturação das classes do padrão Composite e formular a lógica de controle da soma parcial na árvore recursiva.
